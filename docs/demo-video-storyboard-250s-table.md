### 附表 B-2 · 切点形变一览（本片的辨识度）

> **所有切点都是形变，不是硬切。** 每次切点由上一镜的某个物体变成下一镜的某个物体，相机在切点两侧保持同一方向的速度：

| 切点 | 形变 |
|---|---|
| 序 → Ⅰ | 螺旋的粒子收束成手机轮廓；镜头沿螺旋轴继续推进，不停 |
| Ⅰ → Ⅱ | 镜头贴近屏幕，橙色光圈占满画面 → 直接穿屏，从光圈内部穿出到页面 |
| Ⅱ → Ⅲ | 截图的坐标网格线被抽走，变成涡旋的输入光带 |
| Ⅲ → Ⅳ | 涡旋中心吐出一张玻璃卡（Ⅲ 的工具方块化成卡片边缘） |
| Ⅳ → Ⅴ | 诚实白卡的边缘延伸成第一级台阶（good 绿连续） |
| Ⅴ → Ⅵ | 接走红方块的那只手，掌心托着方块 → 第一个交接点的手机 |
| Ⅵ → Ⅶ | 手离开画面，掌心方块化成一颗星点 → 星空后拉 |
| Ⅶ → Ⅷ | 连线的一端落到一张摊开的纸上 → 示范纸面 |
| Ⅷ → Ⅸ | 纸被推远成轨迹板（同一张纸，换了一张图） |
| Ⅸ → Ⅹ | 启用徽章飞起 → 变成收束里的一个数据点 |
